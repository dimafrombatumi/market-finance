# Инструкция по настройке базы данных

## Проблема
RLS (Row Level Security) блокирует добавление данных во все таблицы.

## Решение

### Отключить RLS для всех таблиц

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в раздел "SQL Editor"
4. Выполните следующий SQL скрипт:

```sql
-- Отключаем RLS для всех таблиц
ALTER TABLE products DISABLE ROW LEVEL SECURITY;
ALTER TABLE sales DISABLE ROW LEVEL SECURITY;
ALTER TABLE sale_items DISABLE ROW LEVEL SECURITY;
ALTER TABLE transactions DISABLE ROW LEVEL SECURITY;
```

### Добавить тестовые данные

После отключения RLS запустите скрипты:

```bash
# Добавить тестовые продукты
node setup-products-db.js

# Добавить тестовые транзакции
node add-test-transactions.js
```

## Функционал транзакций

### ✅ Что уже работает:

1. **Форма добавления транзакций** (`TransactionForm.tsx`)
   - Поддержка доходов и расходов
   - Валидация полей
   - Выбор категорий в зависимости от типа
   - Редактирование существующих транзакций

2. **Store для управления транзакциями** (`transactionStore.ts`)
   - CRUD операции
   - Фильтрация по типу и дате
   - Расчет общих сумм
   - Интеграция с Supabase

3. **Страница ExpensesPage**
   - Отображение списка транзакций
   - Кнопки добавления/редактирования/удаления
   - Красивый UI с иконками

### 📝 Поля формы транзакций:

- **Тип** (обязательно): Income или Expense
- **Сумма** (обязательно, > 0)
- **Категория** (обязательно, зависит от типа)
- **Описание** (обязательно)
- **Дата** (по умолчанию текущая)
- **Заметки** (опционально)

### 💰 Категории доходов:

### 💸 Категории расходов:
