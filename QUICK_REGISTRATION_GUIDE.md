# Руководство по быстрому добавлению записей

## Новая функциональность

Добавлена кнопка "Добавить запись" на странице записей на мастер-классы, которая позволяет быстро создавать новые записи без перехода на другие страницы.

## Как использовать

### 1. Открытие формы
- Перейдите на страницу "Записи на мастер-классы"
- Нажмите кнопку "Добавить запись" в правом верхнем углу

### 2. Заполнение формы
- **Имя клиента** (обязательно) - введите имя клиента
- **Email клиента** (обязательно) - введите email адрес
- **Телефон клиента** (необязательно) - введите номер телефона
- **Мастер-класс** (обязательно) - выберите из списка доступных мастер-классов
- **Расписание** (обязательно) - выберите конкретное время и место проведения
- **Способ оплаты** (обязательно) - выберите способ оплаты
- **Заметки** (необязательно) - дополнительные заметки
- **Особые пожелания** (необязательно) - особые требования клиента

### 3. Сохранение записи
- Нажмите кнопку "Добавить" для сохранения записи
- Форма автоматически закроется после успешного сохранения
- Новая запись появится в списке записей

## Особенности

### Валидация
- Проверка обязательных полей (имя, email, мастер-класс, расписание)
- Проверка формата email
- Проверка доступности мест на выбранное расписание

### Связанные поля
- При выборе мастер-класса список расписаний обновляется автоматически
- При смене мастер-класса выбранное расписание сбрасывается

### Отображение расписания
- Расписание показывается в формате: "Пн, 15 фев - 10:00 (Студия Арт-пространство)"
- Включает дату, время и место проведения

## Технические детали

### Компоненты
- `WorkshopRegistrationsPage.tsx` - основная страница с кнопкой и модальным окном
- `Modal` - модальное окно для формы
- `QuickRegistrationForm` - стилизованная форма

### Состояние
- `isAddModalOpen` - открыто ли модальное окно
- `quickFormData` - данные формы быстрого добавления

### Функции
- `handleQuickFormChange` - обработка изменений в форме
- `handleQuickFormSubmit` - отправка формы
- `getAvailableSchedules` - получение доступных расписаний

## Переводы

Добавлены новые ключи переводов:
- `workshopRegistrations.addRegistration` - "Добавить запись"
- `workshops.selectWorkshop` - "Выберите мастер-класс"
- `workshops.selectSchedule` - "Выберите расписание"

## Интеграция с существующей системой

- Использует существующий `workshopRegistrationStore`
- Применяет те же проверки доступности мест
- Обновляет счетчик участников автоматически
- Интегрируется с системой переводов
