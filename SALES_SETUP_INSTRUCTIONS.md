# Инструкция по настройке продаж

## Проблема
RLS (Row Level Security) блокирует добавление данных во все таблицы.

## Решение

### 1. Отключить RLS для всех таблиц

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Перейдите в SQL Editor
3. Выполните команду:

```sql
ALTER TABLE products DISABLE ROW LEVEL SECURITY;
ALTER TABLE sales DISABLE ROW LEVEL SECURITY;
ALTER TABLE sale_items DISABLE ROW LEVEL SECURITY;
ALTER TABLE transactions DISABLE ROW LEVEL SECURITY;
```

### 2. Добавить тестовые данные (в правильном порядке)

```bash
# 1. Сначала добавить продукты
node setup-products-db.js

# 2. Затем добавить транзакции
node add-test-transactions.js

# 3. Наконец добавить продажи
node add-test-sales.js
```

## Функционал продаж

### ✅ Что уже работает:

1. **Форма продаж** (`SaleForm.tsx`)
   - Информация о клиенте
   - Добавление товаров в корзину
   - Автоматический расчет сумм
   - Выбор способа оплаты
   - Валидация формы

2. **Store для продаж** (`salesStore.ts`)
   - CRUD операции
   - Интеграция с таблицами sales и sale_items
   - Фильтрация по дате и статусу
   - Расчет общей выручки

3. **Страница SalesPage**
   - Отображение списка продаж
   - Карточки продаж с деталями
   - Кнопки добавления/редактирования/удаления

### 📝 Поля формы продаж:

**Информация о клиенте:**
- Имя клиента (опционально)
- Email клиента (опционально)
- Телефон клиента (опционально)

**Товары:**
- Выбор продукта из списка
- Количество
- Цена за единицу (автоматически)
- Общая стоимость (автоматически)

**Финансы:**
- Подытог (автоматически)
- Налог (вручную)
- Скидка (вручную)
- Общая сумма (автоматически)

**Дополнительно:**
- Способ оплаты (cash, card, online, other)
- Заметки (опционально)

### 💰 Способы оплаты:
- Cash (наличные)
- Card (карта)
- Online (онлайн)
- Other (другое)

## Проверка работы

После настройки RLS:

1. **Запустите приложение:**
   ```bash
   npm start
   ```

2. **Войдите в систему**

3. **Перейдите на страницу Sales**

4. **Нажмите "Add Sale"**

5. **Заполните форму:**
   - Выберите клиента
   - Добавьте товары
   - Укажите способ оплаты
   - Сохраните

## Особенности

- **Автоматический расчет:** Суммы рассчитываются автоматически
- **Связь с продуктами:** Товары выбираются из существующих продуктов
- **Обновление остатков:** При завершении продажи остатки товаров обновляются
- **Создание транзакций:** Автоматически создается транзакция дохода
