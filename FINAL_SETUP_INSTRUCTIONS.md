# 🚀 Финальная инструкция по настройке

## ✅ Что готово

### 1. **Система авторизации**
- Форма входа/регистрации через email
- Защита маршрутов
- Автоматическое перенаправление

### 2. **Управление продуктами**
- Форма добавления/редактирования продуктов
- Список продуктов с поиском
- Интеграция с базой данных

### 3. **Управление транзакциями**
- Форма добавления доходов/расходов
- Список транзакций с фильтрацией
- Расчет общих сумм

### 4. **База данных**
- Таблицы: products, sales, sale_items, transactions
- Индексы для производительности
- Триггеры для автоматических обновлений

## 🔧 Что нужно сделать

### Единственный шаг - отключить RLS:

1. **Откройте [Supabase Dashboard](https://supabase.com/dashboard)**
2. **Перейдите в SQL Editor**
3. **Выполните команду:**
   ```sql
   ALTER TABLE products DISABLE ROW LEVEL SECURITY;
   ALTER TABLE sales DISABLE ROW LEVEL SECURITY;
   ALTER TABLE sale_items DISABLE ROW LEVEL SECURITY;
   ALTER TABLE transactions DISABLE ROW LEVEL SECURITY;
   ```

### Добавить тестовые данные:

```bash
# Добавить продукты
node setup-products-db.js

# Добавить транзакции
node add-test-transactions.js
```

## 🎯 Как использовать

### 1. **Запуск приложения:**
```bash
npm start
```

### 2. **Авторизация:**
- Откройте http://localhost:3000
- Создайте аккаунт или войдите
- Вас перенаправит на главную страницу

### 3. **Добавление продуктов:**
- Перейдите на страницу "Products"
- Нажмите "Add Product"
- Заполните форму и сохраните

### 4. **Добавление транзакций:**
- Перейдите на страницу "Expenses"
- Нажмите "Add Transaction"
- Выберите тип (Income/Expense)
- Заполните форму и сохраните
