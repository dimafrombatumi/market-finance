# Быстрый запуск мастер-классов

## 🚀 За 5 минут

### 1. Настройте Supabase

1. Создайте проект на [supabase.com](https://supabase.com)
2. Получите URL и API ключ в Settings → API

### 2. Настройте переменные окружения

Создайте файл `.env.local`:

```env
REACT_APP_SUPABASE_URL=https://your-project-id.supabase.co
REACT_APP_SUPABASE_ANON_KEY=your-anon-key-here
```

### 3. Примените схему базы данных

```bash
# Автоматическая настройка
node setup-workshop-database.js

# Или добавьте только тестовые данные
node add-test-workshops.js
```

### 4. Запустите приложение

```bash
npm start
```

### 5. Проверьте функциональность

- Откройте http://localhost:3000
- Перейдите в "Мастер-классы"
- Попробуйте записаться на мастер-класс
- Проверьте страницу "Записи"

## 🔧 Если что-то не работает

### Ошибка подключения к БД
```bash
# Проверьте переменные окружения
cat .env.local
```

### Пустые данные
```bash
# Добавьте тестовые данные
node add-test-workshops.js
```

### Ошибки в консоли
- Проверьте, что схема БД применена
- Убедитесь, что RLS политики настроены
- Проверьте права доступа в Supabase
