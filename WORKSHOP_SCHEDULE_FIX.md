# Исправление проблемы с сохранением расписания мастер-классов

## Проблема
Расписание мастер-классов не сохранялось в базе данных из-за отсутствия компонентов для управления расписанием.

## Решение

### 1. Созданы новые компоненты:

#### `WorkshopScheduleForm.tsx`
- Форма для создания и редактирования расписания
- Поля: дата начала/окончания, время, место, комната, количество участников, примечания
- Валидация полей

#### `WorkshopScheduleModal.tsx`
- Модальное окно для отображения формы расписания
- Поддержка создания и редактирования

### 2. Обновлена страница мастер-классов:

#### `WorkshopsPage.tsx`
- Добавлена кнопка "Календарь" для управления расписанием
- Интегрировано модальное окно расписания
- Добавлены обработчики событий

### 3. Исправлены функции в store:

#### `workshopStore.ts`
- Исправлена функция `addSchedule()` - правильное преобразование дат
- Исправлена функция `updateSchedule()` - корректная передача данных
- Убраны лишние поля из spread оператора

### 4. Добавлены переводы:

#### `ru.json` и `en.json`
- Переводы для всех элементов управления расписанием
- Плейсхолдеры и сообщения об успехе/ошибках

## Как использовать:

1. **Создание расписания:**
   - Откройте страницу мастер-классов
   - Нажмите кнопку "Календарь" на карточке мастер-класса
   - Заполните форму расписания
   - Нажмите "Добавить"

2. **Редактирование расписания:**
   - Нажмите кнопку "Календарь" на карточке мастер-класса
   - Выберите существующее расписание для редактирования
   - Внесите изменения
   - Нажмите "Сохранить"

3. **Просмотр расписания:**
   - Расписание отображается на карточках мастер-классов
   - Показывается дата, время, место и количество участников

## Технические детали:

- **Даты:** Преобразуются в формат YYYY-MM-DD для PostgreSQL
- **Время:** Сохраняется в формате HH:MM
- **Валидация:** Все обязательные поля проверяются
- **Ошибки:** Отображаются пользователю через store
