# Исправление проблемы с редактированием мастер-классов

## Проблема
При редактировании мастер-класса в полях формы не отображались все данные, особенно категория.

## Причина
В функциях загрузки данных из базы (`fetchWorkshops`, `addWorkshop`, `updateWorkshop`) не загружалась информация о категории мастер-класса, поэтому при редактировании поле категории оставалось пустым.

## Решение

### 1. Обновлена функция `fetchWorkshops`:
- Добавлен запрос к таблице `workshop_categories` через JOIN
- Добавлено маппирование `category: workshop.category?.name || ''`

### 2. Обновлена функция `addWorkshop`:
- Добавлен запрос к таблице `workshop_categories` в SELECT
- Добавлено маппирование категории для возвращаемых данных

### 3. Обновлена функция `updateWorkshop`:
- Добавлен запрос к таблице `workshop_categories` в SELECT
- Добавлено маппирование категории для возвращаемых данных

## Технические детали:

### SQL запросы обновлены:
```sql
-- Было:
SELECT *, instructor:instructors(*)

-- Стало:
SELECT *, 
  instructor:instructors(*),
  category:workshop_categories(*)
```

### Маппирование данных:
```javascript
// Добавлено в каждую функцию:
category: data.category?.name || '', // Map category name for form
```

## Результат:
- ✅ При редактировании мастер-класса все поля заполняются корректно
- ✅ Категория отображается в выпадающем списке
- ✅ Все остальные данные (название, описание, инструктор и т.д.) загружаются правильно
- ✅ Форма редактирования работает полностью

## Файлы изменены:
- `src/stores/workshopStore.ts` - обновлены функции fetchWorkshops, addWorkshop, updateWorkshop

Теперь редактирование мастер-классов работает корректно со всеми данными!
