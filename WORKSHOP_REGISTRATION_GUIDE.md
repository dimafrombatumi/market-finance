# Руководство по записи на мастер-классы

## Обзор функциональности

Система записи на мастер-классы позволяет клиентам записываться на различные мастер-классы, управлять записями и отслеживать статус оплаты.

## Основные компоненты

### 1. Форма записи (`WorkshopRegistrationForm.tsx`)
- **Расположение**: `src/components/workshops/WorkshopRegistrationForm.tsx`
- **Функции**:
  - Отображение информации о мастер-классе
  - Сбор данных клиента (имя, email, телефон)
  - Выбор способа оплаты
  - Валидация формы
  - Проверка доступности мест

### 2. Модальное окно записи (`WorkshopRegistrationModal.tsx`)
- **Расположение**: `src/components/workshops/WorkshopRegistrationModal.tsx`
- **Функции**:
  - Отображение формы записи в модальном окне
  - Управление состоянием загрузки
  - Обработка успешной записи

### 3. Страница записей (`WorkshopRegistrationsPage.tsx`)
- **Расположение**: `src/pages/WorkshopRegistrationsPage.tsx`
- **Функции**:
  - Отображение всех записей на мастер-классы
  - Фильтрация по статусу, оплате, мастер-классу
  - Управление статусами записей
  - Статистика записей

### 4. Store для записей (`workshopRegistrationStore.ts`)
- **Расположение**: `src/stores/workshopRegistrationStore.ts`
- **Функции**:
  - CRUD операции с записями
  - Проверка доступности мест
  - Обновление счетчика участников
  - Управление статусами

## Процесс записи

### 1. Клиент выбирает мастер-класс
- Переходит на страницу мастер-классов
- Выбирает интересующий мастер-класс
- Нажимает кнопку "Записаться"

### 2. Заполнение формы записи
- Вводит личные данные (имя, email, телефон)
- Выбирает способ оплаты
- Добавляет заметки или особые пожелания
- Нажимает "Записаться"

### 3. Обработка записи
- Система проверяет доступность мест
- Валидирует данные формы
- Создает запись в базе данных
- Обновляет счетчик участников
- Отправляет уведомление об успехе

## Валидация и проверки

### Валидация формы
- Обязательные поля: имя, email
- Проверка формата email
- Проверка доступности мест

### Проверка доступности мест
- Сравнение текущего количества участников с максимальным
- Блокировка записи при отсутствии мест
- Обновление счетчика после успешной записи

## Статусы записей

### Статус записи
- **pending** - Ожидает подтверждения
- **confirmed** - Подтверждена
- **cancelled** - Отменена
- **completed** - Завершена

### Статус оплаты
- **pending** - Ожидает оплаты
- **paid** - Оплачена
- **refunded** - Возвращена

## Управление записями

### Фильтрация
- По статусу записи
- По статусу оплаты
- По мастер-классу
- Поиск по имени клиента или email

### Действия
- Подтверждение записи
- Отмена записи
- Отметка об оплате
- Просмотр деталей

## Тестовые данные

Для тестирования функциональности создан скрипт `add-test-workshops.js`:

```bash
node add-test-workshops.js
```

Скрипт добавляет:
- 3 преподавателя
- 3 мастер-класса
- 3 расписания
- 3 тестовые записи

## Переводы

Поддерживаются русский и английский языки. Ключи переводов:
- `workshopRegistrations.*` - для страницы записей
- `workshops.*` - для мастер-классов
- `errors.*` - для сообщений об ошибках

## Интеграция с Supabase

### Таблицы
- `workshop_registrations` - записи на мастер-классы
- `workshop_schedules` - расписание мастер-классов
- `workshops` - мастер-классы
- `instructors` - преподаватели

### RLS политики
Убедитесь, что настроены правильные политики Row Level Security для доступа к данным.
