## 🚀 Как использовать

### 1. Добавление товара
1. Перейдите на страницу "Products"
2. Нажмите "Add Product"
3. Заполните форму:
   - Название товара (обязательно)
   - Описание (обязательно)
   - Цена (обязательно, > 0)
   - Себестоимость (опционально)
   - Категория (обязательно)
   - Количество на складе
   - Минимальный уровень запаса
   - SKU (опционально)
   - URL изображения (опционально)
4. Нажмите "Add Product"

### 2. Создание продажи
1. Перейдите на страницу "Sales"
2. Нажмите "New Sale"
3. Заполните информацию о клиенте (опционально)
4. Добавьте товары:
   - Выберите товар из списка
   - Укажите количество
   - Цена и сумма рассчитаются автоматически
5. Проверьте итоговую сумму
6. Выберите способ оплаты
7. Добавьте заметки (опционально)
8. Нажмите "Add Sale"

### 3. Добавление транзакции
1. Перейдите на страницу "Expenses"
2. Нажмите "Add Transaction"
3. Выберите тип: Доход или Расход
4. Выберите категорию
5. Введите описание (обязательно)
6. Укажите сумму (обязательно, > 0)
7. Выберите дату
8. Добавьте заметки (опционально)
9. Нажмите "Add Transaction"

### 4. Просмотр аналитики
1. Перейдите на страницу "Dashboard"
2. Просмотрите ключевые метрики:
   - Общая выручка
   - Общие расходы
   - Чистая прибыль
   - Количество продаж
3. Проверьте товары с низким запасом
4. Просмотрите последние транзакции

### 5. Генерация отчетов
1. Перейдите на страницу "Reports"
2. Выберите период (дата начала и окончания)
3. Просмотрите отчеты:
   - Выручка vs расходы по времени
   - Расходы по категориям
   - Топ товары по выручке
